# PrivateForm

Privacy-first medical form platform for healthcare professionals.

## 🔒 Privacy & Security

- Zero data persistence (patient data deleted immediately after email delivery)
- End-to-end encryption (AES-256)
- No cookies, no tracking
- GDPR compliant
- **Open source**
